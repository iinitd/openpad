Support

Clacko is a client for servers you run. Most connection problems are solved on the server side, so the notes below start there.

Try it without a server

A new install opens a demo workspace with sample files and a scripted agent. You can explore the editor, the file tree, and the chat panel before adding anything.

Connecting a backend

  • Paseo direct — a daemon WebSocket such as ws://192.168.1.10:6767/ws, plus the daemon password if one is set.
  • Paseo relay — paste the pairing link from the daemon. Relay connections are end-to-end encrypted and use TLS.
  • OpenClaw — the gateway WebSocket, such as ws://192.168.1.10:18789. If the gateway asks for pairing, approve the device on the gateway host and reconnect.
  • OpenCode — an OpenCode v2 server URL such as http://192.168.1.10:4096, or a one-time pair link.

localhost means the device running Clacko. On a phone, use the address of the computer on the same network instead.

Common issues

  • Nothing connects on a phone. Confirm the phone and the computer are on the same network, allow local network access for Clacko in iOS Settings, and check that the server listens on the network interface rather than loopback only.
  • OpenCode is rejected. Clacko needs an OpenCode v2 server; the older v1 API is not supported.
  • A server that used to work now fails. Reload the connection from Settings → Connections. Passwords and tokens live on the device, so reinstalling the app clears them.

Get help

Open an issue at github.com/iinitd/puff/issues. Include the backend type, what you expected, and the error text shown in the app. Do not paste passwords or tokens.
