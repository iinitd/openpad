# Clacko site

Static pages for the App Store listing's privacy policy and support URL.

- `/` — landing
- `/privacy.html` — privacy policy
- `/support.html` — support

## How it is served

GitHub Pages serves the `gh-pages` branch. That branch is a single site shared
with the ad-hoc dev client installer:

```
gh-pages/
  index.html privacy.html support.html styles.css icon.png
  dev/            # generated by the iOS Dev Client workflow
```

Two workflows keep it up to date, and neither rewrites the other's files:

- **Site** (`.github/workflows/site.yml`) runs on pushes to `main` that touch
  `site/`, replaces the root files, and leaves `dev/` alone.
- **iOS Dev Client** rebuilds `dev/` and republishes the whole tree, including
  the current `site/` files.

The public address is:

```
https://iinitd.github.io/clacko/
```

That is what `src/settings/about-links.ts` and the App Store Connect fields
use. If the repository is renamed again, the Pages address moves with it, so
update the two constants before the next build.

Pages does not rewrite extensionless paths here, so links keep `.html`, and all
asset paths are relative to this folder.
